# Voovle Chat

Voovle Chat is a real-time web chat application built with Node.js, Express, Socket.IO, HTML, CSS, and JavaScript.

It provides real-time messaging with user roles, image sharing, typing indicators, and administrator controls.

## Features

* Real-time messaging with Socket.IO
* Multiple user roles
* Password-protected accounts
* Administrator controls
* Image uploading and sharing
* Real-time typing indicators
* User mute and unmute controls
* User kick controls
* Message deletion
* Clear chat functionality
* Viewer mode for users without valid chat credentials
* Responsive web interface

## User Roles

### Admin

The administrator can:

* Send messages
* Upload images
* Delete messages
* Clear the chat
* Kick users
* Mute users
* Unmute users
* View connected users

### Chatter

Chatters can:

* Send messages
* Upload images
* Use typing indicators
* View other users

### Viewer

Viewers can:

* Read the chat
* View users

Viewers cannot send messages, upload images, or use typing indicators.
